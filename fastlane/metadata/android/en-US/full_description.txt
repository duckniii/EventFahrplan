<a href="https://hack-mas.at">Håck ma’s Castle</a> is an open castle for all kinds of nerds.

We want to use the castle as an inclusive space and as an accessible entry point for sharing knowledge and exchanging experiences.

Håcking means taking a creative approach to technology—for example with computers, sewing machines, society, and stovetops (food is important!).

<b>Features:</b>

<ul>
<li>Daily overview of all program events (talks, workshops, excursions)</li>
<li>Read detailed event descriptions</li>
<li>Manage events in a personal favorites list</li>
<li>Search and filter all events</li>
<li>Export your favorites list</li>
<li>Set alarms for events</li>
<li>Add events to your calendar</li>
<li>Share event descriptions and links with others</li>
<li>Automatically update the program regularly</li>
<li>View program changes</li>
</ul>
